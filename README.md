# Kvarter – Stockholm city guide (Umbraco 17)

Group project (Grupp Echo). Jira: https://grupp-echo.atlassian.net/jira/software/projects/SCRUM

| | |
|---|---|
| CMS | Umbraco 17 LTS (.NET 10) |
| Local database | SQLite – each developer has their own (`umbraco/Data`, git-ignored) |
| Schema sync | uSync – document types, data types, templates, dictionary and content are saved to `src/Kvarter.Web/uSync/` and committed |
| Languages | Swedish (sv-SE) + English (en-US) |

## Getting started (everyone else)
1. Install the [.NET 10 SDK](https://dotnet.microsoft.com/download) and Visual Studio 2026 / Rider / VS Code.
2. `git clone https://github.com/<owner>/Kvarter.git`
3. `dotnet run --project src/Kvarter.Web`
4. Open the URL shown in the terminal, complete the installer (create your own local admin user).
5. Restart the site once – uSync imports everything the team has committed.

## Working together – rules that keep uSync happy
- **Never work on `main`.** Create a branch per Jira story: `feature/SCRUM-23-place-page`.
- Open a pull request, get one review, then merge.
- **Before you start:** `git pull` on main, merge it into your branch, restart the site (uSync imports).
- **Only edit the document types you own.** Two people changing the same doc type = merge conflict in uSync files.
- If uSync files conflict: keep one version, restart, check the backoffice, then *Settings → uSync → Export* to rewrite the files.
- Media files (`wwwroot/media`) are not committed. Use the same image names or add images via the demo-content story.

## Project structure
```
src/Kvarter.Web/
  Views/_Layout.cshtml            master layout – every page template uses it
  Views/Partials/Site/            header, footer, language switcher
  wwwroot/css/site.css            design tokens (colours, fonts, spacing) + global styles
  wwwroot/js/site.js              tiny scripts (mobile menu)
  uSync/                          generated by uSync – commit it, don't hand-edit
```

## Content structure (already set up – arrives via uSync)
- **Home** (`/en/` and `/sv/`) – the start page. All other pages are created *under* Home.
  The main menu and footer list Home's child pages automatically.
- **Compositions** folder (Settings → Document Types):
  - **SEO** – meta title, meta description, share image. Add it to every page type.
  - **Navigation** – "Hide from navigation" (`umbracoNaviHide`). Add it to every page type.
- **Templates:** `_Layout` is the master template (header, footer, `<head>`, meta tags).

## Creating a new page type (e.g. Place, Article, Event)
1. Settings → Document Types → **Create → Document Type with Template**.
2. Tick **Vary by culture** (so it can be translated) and add the **SEO** and **Navigation** compositions.
3. Open the new template and choose **`_Layout`** as master template, then write the page markup:
```cshtml
@using Umbraco.Cms.Web.Common.PublishedModels;
@inherits Umbraco.Cms.Web.Common.Views.UmbracoViewPage<ContentModels.Place>
@using ContentModels = Umbraco.Cms.Web.Common.PublishedModels;
@{
    Layout = "_Layout.cshtml";
}
<section class="container">
    <h1>@Model.Name</h1>
</section>
```
4. On the **Home** document type → Structure, allow your new type as a child (or as a child of its overview page).
5. Commit the new files under `uSync/` and `Views/` together.

## UI texts
Hard-coded UI texts use dictionary items with an English fallback, e.g.
`@Umbraco.GetDictionaryValueOrDefault("Site.Menu", "Menu")`.
Create the key under *Translation* in the backoffice to add the Swedish text (SCRUM-31).

## Troubleshooting
**"BootFailedException: Boot failed: Umbraco cannot run" on first start**
Umbraco could not create the local SQLite database file. Create an empty one and restart:
```powershell
New-Item -ItemType File -Force src/Kvarter.Web/umbraco/Data/Umbraco.sqlite.db
dotnet run --project src/Kvarter.Web
```
The installer then appears and fills the empty file. Details are in `src/Kvarter.Web/umbraco/Logs/`.
